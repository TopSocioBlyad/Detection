# Детекция той же ямы по ключевым точкам: шаг 1

**Цель:** получить локальные SIFT-признаки эталонной области (яма + прилегающий асфальт), найти их соответствия на втором изображении той же ямы и сохранить результаты. Геометрическая проверка RANSAC появится на следующем этапе.

## Подготовка в VS Code

1. Установите Python 3.11/3.12, Visual Studio Code и расширение Python от Microsoft.
2. Откройте папку проекта в VS Code (**File → Open Folder**).
3. Откройте терминал (**Terminal → New Terminal**) в корне папки.
4. Создайте виртуальное окружение и установите зависимости:

   **Windows PowerShell:**

   ```powershell
   py -3 -m venv .venv
   .\.venv\Scripts\python.exe -m pip install -r requirements.txt
   ```

   **macOS/Linux:**

   ```bash
   python3 -m venv .venv
   .venv/bin/python -m pip install -r requirements.txt
   ```

5. В VS Code нажмите `Ctrl+Shift+P` → `Python: Select Interpreter` → выберите `.venv`.

## Подготовка изображений

Способ A: положите две разные фотографии **одной и той же** ямы в папку `data/` и переименуйте их в `template.png` и `scene.png`.

Способ B: возьмите видео с ямой (например, из Pothole Videos: https://data.mendeley.com/datasets/5bwfg4v4cd/3). Положите **один видеоролик**, а не весь архив, как `data/pothole.mp4` и выполните:

```powershell
python extract_frames.py --video data/pothole.mp4 --first 0 --second 12
```

Извлекутся `data/template.png` и `data/scene.png`. Видео должно действительно показывать ту же яму в обоих кадрах; убедитесь в этом визуально. Если кадры слишком похожи или яма пропадает, измените номера кадров.

## Запуск

**С выбором прямоугольной области мышью** (рекомендуется для настоящих фотографий):

```powershell
python step01_sift.py --select-roi
```

Мышью выделите **яму и окружающий асфальт**, нажмите Enter (или Space). При выборе только тёмной внутренней области ямы SIFT может обнаружить слишком мало точек.

**Без GUI** (пример координат, задайте свои):

```powershell
python step01_sift.py --roi 120 100 240 190
```

**Без выбора области:**

```powershell
python step01_sift.py
```

При этом в качестве эталона берётся всё первое изображение. Можно передать свои имена файлов: `--template path/to/img1.jpg --scene path/to/img2.jpg`.

> Если запускаете команды из внешнего терминала на Windows и виртуальное окружение не активировано, замените `python` на `.\.venv\Scripts\python.exe`. Для macOS/Linux используйте `.venv/bin/python`.

## Результаты

В `results/step01/` появятся:

- `01_template_crop.png` — эталонная область;
- `02_template_keypoints.png` — точки на эталоне;
- `03_scene_keypoints.png` — точки на втором изображении;
- `04_good_matches.png` — линии совпадений после Lowe's ratio test;
- `metrics.json` — количество признаков и совпадений, параметры запуска.

**Важно:** хорошие сопоставления ещё не доказывают, что была найдена именно та же яма. На следующем шаге добавим RANSAC и оценку гомографии. Если совпадений мало, попробуйте область с большим количеством текстуры и более близкие по ракурсу кадры.
