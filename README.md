# Detection — повторное обнаружение дорожных ям

Магистерская курсовая: «Детекция образов на основе сопоставления ключевых точек изображения».

Цель — находить **ту же самую дорожную яму** при изменениях ракурса, масштаба, освещения и размытии. Применение — компьютерное зрение автономных мобильных роботов при исследовании проходимости.

## Исследование

Датасет: Pothole-600 (RGB-изображения, маски `label`, дополнительные данные `tdisp`).
Методы: SIFT, ORB, AKAZE, BRISK; KNN + Lowe ratio; RANSAC + гомография.
Эксперименты: положительные пары (синтетические преобразования одного изображения), отрицательные пары (другие изображения), IoU, precision, recall, F1, инлайеры, время.

## Состояние переноса

Это начальный коммит репозитория. **Исходные скрипты этапов 1–5 и результаты ещё не загружены**.
