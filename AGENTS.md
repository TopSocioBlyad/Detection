# Инструкции для Codex

Проект: магистерская курсовая «Детекция образов на основе сопоставления
ключевых точек изображения».

## Цель и границы

- Повторно обнаруживать ту же физическую дорожную яму на разных изображениях.
- Использовать SIFT, ORB, AKAZE, BRISK, BF/KNN, Lowe ratio, RANSAC и
  гомографию.
- Не заменять задачу нейросетевой детекцией, сегментацией или визуальной
  одометрией.
- Никогда не передавать `pothole_id` функции сопоставления. Метка нужна только
  для формирования выборок и оценки.
- Не сообщать качество на зависимых кадрах как качество независимой повторной
  съёмки.

## Актуальная структура

- `data_reid/` содержит 12 ручных групп и 312 PNG 400×400.
- `reid/` содержит текущий эксперимент на реальных кадрах.
- `results/reid_audit/manifest.csv` является источником метаданных и флагов
  качества для нового эксперимента.
- `legacy/` и `legacy/results/` содержат исторические этапы 1–7.

Не изменять и не перезаписывать `legacy/results/step05` и
`legacy/results/step06`. Конфигурацию
`legacy/results/step05/validation/best_configs.json` считать зафиксированным
baseline. Новые результаты сохранять в отдельных каталогах.

## Научная корректность

- Разделять данные по физическим ямам: одна `pothole_id` не может находиться в
  обучающей и проверочной части одного фолда.
- Подбирать порог только на обучающих идентичностях соответствующего фолда.
- Исключать строки manifest с точными или близкими копиями.
- Если `capture_id` известен, не использовать два кадра одной записи как
  независимую положительную пару. Текущие `capture_id` неизвестны; явно
  сохранять это ограничение.
- IoU вычислять только при наличии достоверной маски конкретного кадра.
- Не использовать итоговые группы для повторной настройки baseline.

## Окружение и проверки

Проверенная среда: Python 3.12, opencv-contrib-python 4.11.0.86, NumPy 2.5.4,
Matplotlib 3.11.2. Использовать `.venv/bin/python` и запускать команды из корня
репозитория. В облачной среде задавать
`MPLCONFIGDIR=/tmp/detection-matplotlib` для построения графиков.

Перед завершением изменений выполнить:

```bash
PYTHONPATH=. .venv/bin/python -m unittest discover -s tests -v
.venv/bin/python -m pip check
.venv/bin/python -m compileall -q reid tests legacy
git diff --check
```

Работать в отдельной Git-ветке, создать Pull Request и не объединять его в
`main` автоматически. Не коммитить `.venv`, токены или временные файлы.
